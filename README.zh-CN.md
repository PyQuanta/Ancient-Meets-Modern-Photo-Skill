# PyQuant-XQX · 小清新萌萌哒「古装穿越现代」写真 Skill

> English version: [README.md](README.md)

把神话/古装角色放进**真实的现代日常生活**，用日系小清新胶片质感拍出来。
威严的角色认真做着最平凡的小事——反差自然产生活泼与萌感，全程治愈系。

> 🌸 示例：及腰芒草花田里，古装少女手捧野花 + 一杯冰咖啡；满脸虬髯的牛魔王在娃娃机前全神贯注，机内一只粉色兔子。

## 快速上手

1. 读 `SKILL.md` 拿到 prompt 主模板与五档情绪弹药库；
2. 备一张**脸占画面 ≥1/4** 的角色近景照片做锚点（裁脸方形化 1024×1024）；
3. 按模板出图（胶片质感自带随机性，同 prompt 出 2–3 张挑）；
4. 最后用脚本裱相纸边框、叠竖排注记（**文字永远后期叠，AI 写字必乱码**）：

```bash
python scripts/photo_frame.py 输入.png 输出.png \
  --ratio 0.055 --crop-bottom 0.06 --bottom-extra 0.9 \
  --title-in-margin --halo 0.5 \
  --caption "風にゆれて" --caption2 "はるのいろ" --title "野原の 小さな幸せ"
```

依赖：仅 Pillow（`pip install pillow`），Python ≥ 3.9。
